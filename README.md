# Agentic Architecture Research

This repository contains a small research harness for comparing different agentic LLM architectures on two task families:

1. ARC-AGI visual reasoning tasks.
2. Synthetic meeting-scheduling tasks with time-window constraints.

The code is intentionally lightweight and script-driven. There is no web app or training loop here. The focus is on running controlled inference experiments, measuring output correctness, and comparing how different orchestration patterns affect token usage, runtime, and success rate.

## What This Project Tests

The experiment compares three agent structures defined in [graphs.py](graphs.py):

- Single-Agent Baseline: one direct LLM call solves the task.
- Planner-Executor: one node writes a plan, another executes it.
- Solver-Critic: one node proposes an answer, a critic reviews it, and the solver retries on failure.

Each architecture uses the same underlying chat model, currently configured in [graphs.py](graphs.py) as `gpt-5.1` with temperature `0`.

The main evaluation loop lives in [evaluate.py](evaluate.py). It loads tasks, converts them into prompts, invokes the selected graph, and prints the resulting answer, correctness flag, token count, loop count, and elapsed time.

## Repository Structure

The project is small, so the folder layout maps almost directly to the evaluation pipeline:

- [config.py](config.py): task lists for ARC and synthetic scheduling.
- [prompt_manager.py](prompt_manager.py): converts ARC JSON tasks into prompt text.
- [graphs.py](graphs.py): LangGraph node definitions and graph compilation.
- [evaluate.py](evaluate.py): experiment runner and console reporting.
- [tasks/ARC-AGI-1/](tasks/ARC-AGI-1/): ARC task JSON files grouped by difficulty.

## Requirements

You will need:

- Python 3.10 or newer.
- An OpenAI API key.
- Network access for the model calls.

The code depends on the LangChain and LangGraph stack used in [graphs.py](graphs.py):

- `langchain-openai`
- `langchain-core`
- `langgraph`

If those packages are not already installed in your environment, install them with `pip`.


## Running The Experiment

Run the full evaluation suite from the repository root:

```bash
python evaluate.py
```

That script currently runs both task families:

- ARC-AGI evaluation.
- Scheduling evaluation.

Each architecture is evaluated against the configured tasks, and the console output reports the result for every task.

## Reproducibility

The experiment is configured for deterministic-style inference as much as the API allows:

- temperature is set to `0`.
- the same model is used across graphs.
- prompts are fixed by the repository code and task files.

The main sources of variation are model updates and any changes you make to prompts, architecture definitions, or task selection.
